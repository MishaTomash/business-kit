1. ВІЗУАЛЬНЕ ПОРІВНЯННЯ: для кожної сторінки зроби скріншот на 390 і 1440 px поруч із макетом із design/pages/*.png; склади таблицю розбіжностей (що, наскільки важливо) і виправ усе, що впливає на враження або читабельність.
2. АВТОПЕРЕВІРКИ: build без попереджень; CSP-тест; перевірка зовнішніх запитів (мають бути лише власні); Lighthouse мобільний (Performance ≥ 90, Accessibility ≥ 95, SEO ≥ 95, CLS < 0,05) для 5 сторінок; ліміти: JS ≤ 90 КБ gzip, CSS ≤ 30 КБ gzip, шрифти лише latin + cyrillic (+ext для ₴).
3. ДОСТУПНІСТЬ: клавіатура на всіх інтерактивних елементах, фокус видно, контраст AA (включно з анімованими станами), alt/aria, порядок заголовків, prefers-reduced-motion, без JS.
4. СЛАБКИЙ ТЕЛЕФОН: емуляція CPU ×4 і мережі 4G: LCP < 2,5 с, головна не фризить при скролі.
5. Тести відбитка запускаються однією командою, включно з порівнянням із ka-lib.js.
6. ПЕРЕВІРКА ФОРМУЛЮВАНЬ: пошук по src/, content/ і згенерованому HTML заборонених фраз («для вашого каналу», «словесна», «кросворд» поза сторінкою Слововира, «підписники» як єдина аудиторія); перелік винятків.
7. ДОКУМЕНТАЦІЯ: README.md (дизайн-система, як змінювати кольори, шрифти й відбиток), docs/ADD-GAME.md (як нова гра отримує відбиток, колір, жанр, сторінку, превʼю), docs/DESIGN-IMPORT.md позначити «виконано» з відхиленнями від макета.
