# Як додати нового бота на сайт

Кожен бот на сайті — це один об'єкт у файлі `src/data/projects.ts`. Сторінку проєкту,
картку в списку, калькулятор і прогноз прибутку сайт будує з нього сам: верстку чіпати не потрібно.

Увесь шлях займає 15–30 хвилин:

1. [Обрати напрям](#1-напрям) (або створити новий).
2. [Додати проєкт](#2-проєкт) у `projects.ts` за шаблоном.
3. [Заповнити економіку](#3-економіка-калькулятор) для калькулятора.
4. [Додати фото й посилання](#4-фото-й-посилання-на-бота) (можна пізніше).
5. [Перевірити локально](#5-перевірка-локально) і [викласти на сервер](#6-публікація).

---

## 1. Напрям

Напрями (категорії) лежать у `src/data/categories.ts`. Зараз є:

| `id` | Назва |
| --- | --- |
| `media` | Медіа та контент |
| `ai` | AI-сервіси |
| `education` | Навчання |
| `shops` | Магазини |
| `games` | Ігри та розваги |

Якщо бот підходить під один із них, запам'ятайте його `id` і переходьте до кроку 2.

Новий напрям — це ще один об'єкт у масиві `CATEGORIES`:

```ts
{
  id: 'finance',                 // латиницею, потрапляє в адресу: /#/c/finance
  art: 'shop',                   // ілюстрація на картці (список нижче)
  name: 'Фінанси',
  description: 'Боти для обліку витрат, нагадувань про платежі й курсів валют.',
  icon: 'coins',                 // іконка (список нижче)
  accent: '#22d3ee',             // колір напряму
},
```

Порядок у масиві — це порядок плиток вибору напряму на головній. Напрям без жодного доступного
проєкту на головній згортається в рядок «Готуємо: …», а його сторінка показує стан «Скоро».

## 2. Проєкт

Відкрийте `src/data/projects.ts` і вставте шаблон **перед** блоком
`/* === ЗАГЛУШКА ...`. Заповніть усе, що в лапках.

```ts
  /* ===================================================== НАЗВА БОТА */
  {
    // --- Основне -------------------------------------------------------
    id: 'qr-generator',            // латиницею, унікальний: адреса /#/p/qr-generator
    categoryId: 'media',           // id напряму з кроку 1
    status: 'available',           // 'available' — можна купити; 'soon' — «Скоро», не відкривається
    name: 'QR Generator',
    shortName: 'QR',               // коротка назва для вкладок і кнопок (необов'язково)
    icon: 'box',
    accent: '#8b5cf6',
    // Колірний світ: панель на головній і hero сторінки проєкту (необов'язково, див. нижче)
    theme: { bg: '#2B1B5E', ink: '#FFFFFF', accent: '#FFC233', onAccent: '#2B1B5E' },
    tagline: 'Один рядок під назвою в списку проєктів.',
    howItEarns:
      'Хто платить і за що, простими словами. 2–3 речення: що безкоштовно, за що беруть зірки.',

    // --- Ціни для покупця проєкту (вас купують) ----------------------
    priceUah: 3000,                // разова ціна запуску
    monthlyUah: 400,               // щомісячна плата за сервер і підтримку

    // --- Ціни для клієнтів усередині бота (таблиця на сторінці) -------
    customerPrices: [
      { label: 'Безкоштовно', price: '3 коди' },
      { label: '10 кодів', price: '10 ⭐' },
      { label: '50 кодів', price: '40 ⭐' },
    ],

    // --- Орієнтири для новачка ---------------------------------------
    firstClientDays: [3, 10],      // днів до першого клієнта (від–до)
    dailyMinutes: [30, 60],        // хвилин роботи на день (від–до)
    trafficSource: 'TikTok',       // звідки люди: підставляється в текст калькулятора

    // --- Економіка для калькулятора (див. крок 3) ---------------------
    economics: { kind: 'stars', payerRate: 0.05, arppuStars: 40, apiCostPerPayerUsd: 0 },

    // --- Як виглядає покупка: демо-чат у телефоні --------------------
    demo: [
      { from: 'user', text: 'https://my-site.com' },
      { from: 'bot', text: 'QR-код готовий ✓', button: '10 кодів за 10 ⭐' },
      { from: 'system', text: 'Оплачено 10 ⭐' },
      { from: 'bot', text: 'Пакет активовано.\nНадсилайте наступне посилання!' },
    ],

    // --- Де шукати клієнтів ------------------------------------------
    channels: [
      {
        icon: 'megaphone',
        title: 'Короткі відео',
        description: 'Що показувати й чому це працює.',
        cost: 'free',              // 'free' або 'paid'
      },
      {
        icon: 'trend',
        title: 'Реклама в Telegram-каналах',
        description: 'Коли бот уже заробляє.',
        cost: 'paid',
      },
    ],

    // --- Короткий огляд плану розвитку -------------------------------
    plan: [
      { period: 'Тиждень 1', title: 'Старт', tasks: ['Завдання 1', 'Завдання 2', 'Завдання 3'] },
      { period: 'Тижні 2–4', title: 'Регулярність', tasks: ['…'] },
      { period: 'Місяць 2+', title: 'Ріст', tasks: ['…'] },
    ],

    // --- Куди рости далі ---------------------------------------------
    directions: [
      { title: 'Нова функція', description: 'Одне речення.' },
    ],

    // --- Що входить у покупку ----------------------------------------
    includes: [
      'Бот під вашою назвою й аватаром',
      'Оплата в Telegram Stars',
      'Адмін-команди: статистика, повернення, бонуси',
      'Сервер і технічна підтримка',
    ],

    // --- Коли бот запрацює (крок 4) -----------------------------------
    // botUrl: 'https://t.me/your_bot',
    // image: '/images/projects/qr-generator/main.webp',
    // screenshots: [
    //   { src: '/images/projects/qr-generator/1.webp', alt: 'Що на скріншоті' },
    // ],
  },
```

### Довідник полів

| Поле | Обов'язкове | Що це |
| --- | --- | --- |
| `id` | так | Латиниця, цифри, дефіс. Змінювати після публікації не варто: старі посилання перестануть працювати |
| `categoryId` | так | Має точно збігатися з `id` напряму |
| `status` | так | `'available'` або `'soon'` |
| `name`, `tagline`, `howItEarns` | так | Назва, рядок у списку, пояснення моделі заробітку |
| `icon`, `accent` | так | Іконка й колір (hex) |
| `shortName` | ні | Коротка назва для вкладок і кнопок, напр. `'Слововир'`. Без неї береться частина `name` до двокрапки |
| `theme` | ні | Колірний світ продукту: `{ bg, ink, accent, onAccent }`. Без нього кольори виводяться з `accent` |
| `priceUah`, `monthlyUah` | так | Ваші ціни для покупця проєкту, у гривнях |
| `firstClientDays`, `dailyMinutes` | так | Діапазони `[від, до]` |
| `trafficSource` | так | Наприклад `'TikTok'`, `'Instagram'` |
| `economics` | так | Припущення калькулятора (крок 3) |
| `channels`, `plan`, `directions` | так | Порожній масив `[]` — блок не показується |
| `includes` | так | Список того, що отримує покупець |
| `customerPrices` | ні | Таблиця «Ціни для ваших клієнтів» |
| `demo` | ні | Демо-чат у макеті телефона |
| `screen` | ні | `'crossword'` — макет гри замість чату (для Mini App ігор) |
| `art` | ні | Стара ілюстрація; у новому дизайні не показується, залишена для сумісності |
| `botUrl` | ні | Посилання на живого бота → кнопки «Спробувати бота» |
| `image` | ні | Справжній скріншот замість макета телефона й мініатюри |
| `screenshots` | ні | Галерея «Як виглядає бот» |

### Доступні іконки (`icon`)

`download` `sparkles` `bag` `brain` `star` `box` `coins` `wallet` `chart` `trend` `rocket`
`megaphone` `send` `key` `map` `flag` `clock` `calendar` `shield` `server` `percent` `codeOff`
`check` `arrowRight` `close`

Нова іконка додається в `src/lib/icons.ts` (SVG-шлях 24×24).

### Колірний світ (`theme`)

Кожен бот на головній має власну повноширинну панель, а його сторінка відкривається
в тому самому кольорі. Кольори задаються полем `theme`:

| Поле | Що це |
| --- | --- |
| `bg` | Тло панелі й hero сторінки |
| `ink` | Колір тексту на тлі |
| `accent` | Колір головної кнопки («Детальніше», «Спробувати бота») |
| `onAccent` | Колір тексту на головній кнопці |

Усі поля необов'язкові. Якщо `theme` немає, тлом стає `accent` проєкту, а текст сайт
сам обирає білим або темним, залежно від того, що краще читається.

Перевірте контраст `ink` на `bg` і `onAccent` на `accent`: щонайменше 4,5 : 1
(наприклад, на webaim.org/resources/contrastchecker). Приклади з чинних ботів:

```ts
theme: { bg: '#0E3B3F', ink: '#E9FBF8', accent: '#3FE0C5', onAccent: '#06292B' }, // Голос → Текст
theme: { bg: '#1747C9', ink: '#FFFFFF', accent: '#FFFFFF', onAccent: '#1747C9' }, // Downloader
theme: { bg: '#FFF6E9', ink: '#17191D', accent: '#17191D', onAccent: '#FFF6E9' }, // Слововир
```

### Демо-чат

- `from`: `'user'` (зелена бульбашка справа), `'bot'` (біла зліва), `'system'` (сіра плашка посередині, напр. «Оплачено»).
- `button` — кнопка під повідомленням бота.
- `\n` у тексті — перенос рядка.
- 3–5 повідомлень: найстаріші ховаються вгорі, як у справжньому чаті.
- Демо-екрани підписані на сайті «Демо». Справжній скріншот (`image`) такого підпису не має.

## 3. Економіка (калькулятор)

Калькулятор на сторінці проєкту, прогноз на картці й «Вихід у плюс» рахуються з поля `economics`.
Це припущення, які бачать покупці, тож ставте обережні значення й оновлюйте їх реальними
цифрами з `/stats` після першого місяця.

### Бот із Telegram Stars

```ts
economics: { kind: 'stars', payerRate: 0.05, arppuStars: 40, apiCostPerPayerUsd: 0 }
```

| Поле | Що це | Як оцінити |
| --- | --- | --- |
| `payerRate` | Частка користувачів, що платять за місяць (0.05 = 5 %) | Обережно: 0.03–0.10. Реально: покупці ÷ нові користувачі за місяць |
| `arppuStars` | Скільки зірок у середньому витрачає один покупець за місяць | Найпопулярніший пакет або зароблені зірки ÷ покупці |
| `apiCostPerPayerUsd` | Витрати на зовнішні API на одного покупця, $ | 0, якщо бот на безкоштовних сервісах |

### Магазин фізичних товарів

```ts
economics: { kind: 'orders', payerRate: 0.03, avgOrderUah: 900, marginRate: 0.3 }
```

`avgOrderUah` — середній чек, `marginRate` — націнка (0.3 = 30 %).

### Як рахується

```
покупці       = люди за місяць × payerRate
виручка (₴)   = покупці × arppuStars × 0,013 $ × 41,5 ₴
витрати (₴)   = monthlyUah + покупці × apiCostPerPayerUsd × 41,5 ₴
чистий дохід  = виручка − витрати
```

Курс виплати зірок і курс гривні змінюються в `src/data/site.ts` → `RATES`.

На картці в списку напряму показується прогноз для 500 людей на місяць (`PREVIEW_TRAFFIC` у `site.ts`).
Якщо він мінусовий, замість мінуса сайт сам покаже «у плюс від ≈ N людей на місяць».

## 4. Фото й посилання на бота

Можна додати одразу або пізніше, кожне поле окремо.

1. Створіть папку `public/images/projects/<id>/` (наприклад, `public/images/projects/qr-generator/`).
2. Покладіть туди скріншоти: вертикальні, приблизно 590×1280, формат `.webp` або `.png`.
3. Розкоментуйте в проєкті `botUrl`, `image`, `screenshots`.

Шлях у коді пишеться **без** `public`: файл `public/images/projects/qr-generator/1.webp`
→ `'/images/projects/qr-generator/1.webp'`.

> **Увага до регістру букв.** Windows не розрізняє `Main.webp` і `main.webp`, а сервер (Linux) розрізняє.
> Якщо локально картинка є, а на сайті ні, перевірте, що назва файлу й шлях у коді збігаються буква в букву.
> Найпростіше: лише малі латинські літери й дефіси.

Для Mini App гри `botUrl` краще давати прямим посиланням на гру: `https://t.me/<бот>/<app>`.

## 5. Перевірка локально

```powershell
npm run dev
```

Відкрийте http://localhost:5173 і перевірте:

- [ ] На головній новий бот є в плитці свого напряму (лічильник зріс) і має власну кольорову панель.
- [ ] Якщо є `demo`, `screen` або `image`, бот з'явився в сцені телефонів у hero.
- [ ] Бот є на сторінці свого напряму великою карткою.
- [ ] Сторінка проєкту відкривається, усі блоки заповнені.
- [ ] Калькулятор рахує правдоподібно: посуньте повзунок, перевірте «Окупність».
- [ ] Демо-чат читається, повідомлення не обрізані.
- [ ] Текст на кольоровій панелі добре читається (перевірте `theme`).
- [ ] Кнопка «Спробувати бота» (якщо є `botUrl`) відкриває саме цього бота.
- [ ] Вигляд на телефоні: `F12` → значок телефона (Device Toolbar).
- [ ] У консолі браузера (`F12` → Console) немає попереджень `[data] ...`.

Потім перевірка типів, як на сервері:

```powershell
npm run build
```

Якщо збірка падає, TypeScript пише файл і рядок. Найчастіші причини:

| Помилка | Що виправити |
| --- | --- |
| `Property 'tagline' is missing` | Пропущене обов'язкове поле |
| `Type '"downlaod"' is not assignable to type IconName` | Описка в назві іконки або ілюстрації |
| `Type '"availible"' is not assignable` | `status` лише `'available'` або `'soon'` |
| `',' expected` | Пропущена кома між полями чи об'єктами |

Попередження в консолі `[data] Project "..." has unknown categoryId` означає, що `categoryId`
не збігається з жодним напрямом. Попередження `Duplicate project ids` — що такий `id` уже є.

## 6. Публікація

```powershell
git add .
git commit -m "Новий проєкт: QR Generator"
git push
```

На сервері:

```bash
~/apps/business-kit/deploy/update.sh
```

Скрипт сам підтягне зміни, перевірить типи, збере сайт і викладе його. Якщо збірка впаде,
старий сайт продовжить працювати: файли замінюються лише після успішної збірки.

Відкрийте сайт і перевірте новий проєкт. Якщо зміни не видно, оновіть сторінку
з очищенням кешу: `Ctrl+Shift+R` (на телефоні — закрийте вкладку й відкрийте знову).

## Короткий чекліст перед публікацією

- [ ] Ціни для клієнтів у `customerPrices` збігаються з пакетами в самому боті.
- [ ] На сайті не обіцяно функцій, яких бот поки не вміє.
- [ ] `payerRate` і `arppuStars` обережні, а не оптимістичні.
- [ ] Ціни запуску (`priceUah`, `monthlyUah`) — ваші актуальні.
- [ ] `npm run build` проходить без помилок.
- [ ] Заглушку з тією ж назвою (якщо була зі `status: 'soon'`) видалено.
