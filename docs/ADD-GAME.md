# Як додати гру на сайт

Кожна гра на сайті — це один об'єкт у файлі `src/data/games.ts`. З нього сайт сам будує:

- картку в каталозі `/games` (і фільтр жанрів, коли ігор стане більше шести);
- лічильник «У каталозі N ігор» на головній;
- власну сторінку `/games/<id>` з калькулятором, планом і карткою покупки;
- окремий HTML-файл цієї сторінки з власними `<title>`, описом і прев'ю посилання для Telegram.

Верстку чіпати не потрібно. Увесь шлях займає 15–30 хвилин:

1. [Додати гру](#1-додати-гру) у `games.ts` за шаблоном.
2. [Заповнити економіку](#2-економіка-калькулятор) для калькулятора.
3. [Обкладинка й скріншоти](#3-обкладинка-й-скріншоти) (можна пізніше).
4. [Картинка прев'ю посилання](#4-картинка-прев'ю-посилання).
5. [Перевірити](#5-перевірка) і [опублікувати](#6-публікація).

## 1. Додати гру

Відкрийте `src/data/games.ts` і вставте шаблон у масив `GAMES`. Порядок у масиві — це порядок у
каталозі (доступні ігри все одно стоять перед тими, що «у розробці»).

```ts
  /* ===================================================== НАЗВА ГРИ */
  {
    id: 'slovo-dnia',              // латиниця, цифри й дефіс; адреса сторінки: /games/slovo-dnia
    status: 'available',           // 'available' — можна грати й купити; 'soon' — «У розробці»
    name: 'Слово дня',
    genre: 'Вгадай слово',         // з цього поля будується фільтр жанрів
    tagline: 'Один рядок суті для картки в каталозі.',
    howItEarns: 'Хто платить і за що, 2–3 речення простими словами.',
    mechanics: ['Механіка 1', 'Механіка 2', 'Механіка 3'],

    // Колірний світ: обкладинка й верх сторінки гри. Контраст ink на bg — щонайменше 4,5 : 1.
    theme: { bg: '#1f7a47', ink: '#ffffff', tile: '#ffffff', tileInk: '#0d2a1c' },
    coverWord: 'ДЕНЬ',             // слово з плиток на обкладинці, до 7 літер

    priceUah: PRICING.launchUah,   // разова ціна запуску (зараз 1 500 ₴)
    monthlyUah: PRICING.monthlyUah,// щомісячна плата (зараз 99 ₴)

    customerPrices: [              // ціни для гравців; ★ можна писати як ⭐
      { label: 'Слово дня', price: 'безкоштовно' },
      { label: 'Додаткова спроба', price: '1 ★' },
    ],
    firstClientDays: [5, 14],      // орієнтир: днів до першого платника
    dailyMinutes: [20, 40],        // орієнтир: хвилин на день на просування
    trafficSource: 'TikTok',       // звідки приходять гравці (текст у калькуляторі)
    economics: { kind: 'stars', payerRate: 0.03, arppuStars: 15, apiCostPerPayerUsd: 0 },

    includes: ['Що входить у запуск, по пункту на рядок'],
    channels: [{ title: 'Канал просування', description: 'Як саме', cost: 'free' }],
    plan: [{ period: 'Тиждень 1', title: 'Запуск', tasks: ['Задача 1', 'Задача 2'] }],

    botUrl: 'https://t.me/your_game_bot/play', // дає кнопку «Пограти»
    // demo: [{ clue: 'Питання', answer: 'ВІДПОВІДЬ' }], // маленька демо-гра на сторінці (3–4 слова)
    // screenshots: [{ src: '/images/games/slovo-dnia/1.webp', alt: 'Що на скріншоті' }],
    // cover: '/images/games/slovo-dnia/cover.webp',   // справжня обкладинка замість плиток
    // ogImage: '/og/slovo-dnia.png',                   // власна картинка прев'ю (див. крок 4)
  },
```

### Статуси й заглушки

| Що в даних | Що бачить відвідувач |
| --- | --- |
| `status: 'available'` | «Доступна», кнопки «Пограти» й «Хочу таку гру», демо, калькулятор, план, покупка |
| `status: 'soon'` | «У розробці», опис і механіки, кнопка «Повідомити про запуск». Без покупки й калькулятора |
| `mock: true` | Те саме, що `soon`, **навіть якщо помилково стоїть `available`** |

Зараз у каталозі чотири заглушки з `mock: true`. Поки вони є, консоль у `npm run dev`
попереджає: «Досі заглушки (mock): …». Їхні ціни позначені коментарем `// MOCK: замінити`.

### Як перетворити заглушку на справжню гру

1. Приберіть рядок `mock: true`.
2. Поставте `status: 'available'` і додайте `botUrl`.
3. Замініть усі значення з коментарем `// MOCK: замінити` справжніми.
4. Зробіть картинку прев'ю (крок 4), якщо назва чи обкладинка змінились.

## 2. Економіка (калькулятор)

Калькулятор на сторінці гри рахує прибуток власника гри з `economics`
(логіка в `src/lib/economics.ts`, її не змінюйте):

| Поле | Що означає | Звідки брати |
| --- | --- | --- |
| `payerRate` | частка гравців, які платять хоча б раз на місяць | обережно: 0,02–0,05 |
| `arppuStars` | скільки зірок у середньому витрачає один платник за місяць | з адмін-панелі справжньої гри |
| `apiCostPerPayerUsd` | змінні витрати на платника, $ | для словесних ігор зазвичай 0 |

Курс виплати зірок і курс гривні лежать у `src/data/site.ts` → `RATES`.
Прогнози на сайті завжди підписані як модель, а не гарантія доходу.

## 3. Обкладинка й скріншоти

- Без файлів обкладинка складається з плиток `coverWord` у кольорах `theme`. Цього достатньо.
- Справжня обкладинка: файл 800×600 (`.webp` або `.png`) у `public/images/games/<id>/` і поле `cover`.
- Скріншоти: вертикальні, приблизно 590×1280, у тій самій папці, поле `screenshots`.
  Якщо в гри є `demo`, на сторінці показується демо-гра, а не скріншоти.

## 4. Картинка прев'ю посилання

Коли посилання на `/games/<id>` надсилають у Telegram, під ним з'являється прев'ю:
назва бренду, заголовок, опис і картинка. Заголовок і опис сайт бере з даних гри сам.
Картинку треба покласти файлом:

1. Запустіть `npm run dev` і відкрийте `http://localhost:5173/lab/og.html`.
2. Знайдіть свою гру й натисніть «Завантажити PNG».
3. Покладіть файл у `public/og/` під назвою `<id>.png` (назва написана поруч із кнопкою).

Якщо файлу немає, збірка попередить і візьме загальну картинку `public/og/default.png`.
Власну картинку з іншою назвою можна вказати полем `ogImage`.

У `.env` має стояти правильна адреса сайту `VITE_SITE_URL=https://klitynka.online`: Telegram завантажує картинку саме за нею.
Telegram запам'ятовує прев'ю. Щоб оновити вже показане прев'ю, надішліть посилання боту `@WebpageBot`.

## 5. Перевірка

```bash
npm run dev      # http://localhost:5173
```

- Гра з'явилась у каталозі `/games`, правильний статус і жанр.
- Блок на головній «N гра вже працює» і «ще M у розробці» порахував гру правильно (рахуються лише доступні, заглушки йдуть у «ще»).
- Сторінка `/games/<id>` відкривається; для `available` працює «Пограти», для `soon` його немає.
- Без помилок у консолі (крім попередження про заглушки, поки вони є).

```bash
npm run build    # перевірка типів + збірка + prerender
npm run preview  # перегляд готової збірки
```

Після збірки в `dist/games/<id>/index.html` має бути `<meta property="og:title" …>` з назвою гри, а адреса гри
з'являється в `dist/sitemap.xml`. Як виглядатиме посилання в Telegram, показує макет (з og-мета зібраної сторінки):

```bash
node lab/tg-preview.mjs /games/<id>     # пише lab/tg-preview.html, відкрийте його в браузері
```

## 6. Публікація

```bash
git add . && git commit -m "Нова гра: <назва>" && git push
# на сервері:
~/apps/business-kit/deploy/update.sh
```
