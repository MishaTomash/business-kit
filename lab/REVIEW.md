# Етап 3: перевірка за чеклистом

Скріншоти 390 і 1440 px і відео надіслані в чаті. Повний рух видно на відео; повносторінкові
скріншоти зняті з `prefers-reduced-motion`, щоб закріплені сцени не накладались одна на одну.

## Вимірювання (продакшн-збірка під CSP сервера)

| Що | Ліміт | Результат |
| --- | --- | --- |
| JS (gzip, разом з lenis) | ≤ 110 КБ | 27 КБ |
| CSS (gzip) | ≤ 30 КБ | 8,7 КБ |
| Шрифти | latin + cyrillic | latin + cyrillic; у Geologica ще cyrillic-ext лише для ₴ (11 КБ) |
| Lighthouse мобільний: Performance | ≥ 85 | 97 / 98 / 94 (головна / каталог / Слововир) |
| Accessibility | ≥ 95 | 100 / 100 / 100 |
| CLS | < 0,05 | 0 / 0 / 0 |
| Помилки CSP у консолі | 0 | 0 |
| Без JS | вміст видно | так: кожна сторінка — готовий HTML |

Performance міряний на локальному сервері без gzip і кешу; на nginx з gzip буде не гірше.

## Головна

- **Чи впізнав би дизайнер AI-шаблон?** Найближче до шаблону були б FAQ-картки з плюсом і стандартний футер.
  FAQ зроблено в мові плиток (контур, «дно», перемикач-плитка), футер свідомо тихий. Hero не центрований,
  без бейджа над заголовком, з плитками-словами про бізнес замість макета телефона.
- **«Шлях зірки»:** сцена на всю ширину; праворуч баланс гри з плиток наповнюється до мінімуму виведення
  (1 000 ★), на станції «21 день» показує очікування, наприкінці плитки перевертаються в гривні.
  Факт змінюється перевертанням плиток по черзі, без напівпрозорого накладання.
- **Завіса:** нова секція наїжджає на попередню своїм кольором, кольори не змішуються, контраст AA і під час переходу.
- **ЗАБОРОНЕНО:** не використано — немає індиго й градієнтів, світіння, скла, блобів, частинок, сіток на фоні,
  Inter/Unbounded, кремового тла із засічками й теракотою, пігулок-бейджів, емодзі (зірка — SVG-іконка),
  макетів телефонів, порожніх слів на кшталт «потужно» чи «легко». Кожне твердження з цифрою з даних.
- **Одна головна дія на екран:** так.
- **Шкала шрифтів:** 6 розмірів (16, 17, 19, h3, h2, h1). Найменший текст 16 px.
- **Ціни й відсоток:** 1 500 ₴ разово, 99 ₴/міс, 0 % зі зірок показано як перевагу без пунктирної рамки.

## Каталог /games

- Перевірено на 1, 3, 5, 12 і 20 іграх: одна гра — широка картка, 2–3 — у ряд, більше — сітка;
  фільтр жанрів з'являється з 7 ігор і працює.
- Тимчасові ігри сама з'являлись у каталозі, фільтрі, лічильнику на головній і на власних сторінках;
  після перевірки прибрані.
- Перехід картка → сторінка гри: обкладинка перетікає в hero (View Transitions), без API — звичайна зміна сторінки.

## Сторінка гри

- **available (Слововир):** «Пограти» й «Хочу таку гру», робоча демо-гра на 4 слова з підказкою, ціни для гравців,
  механіки, калькулятор (`economics.ts` не змінювався), що входить, план, де шукати гравців, картка покупки.
- **soon / mock:** «У розробці», опис і механіки, «Повідомити про запуск». Без «Пограти», покупки й калькулятора;
  ціни заглушок не показуються.

## 404
