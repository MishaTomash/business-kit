Картинки прев'ю посилань

Кожна картинка має розмір 1200×630. Натисніть «Завантажити PNG» і покладіть файл у папку public/og/ під назвою, яка написана поруч (або виконайте node lab/og-export.mjs при запущеному npm run dev, щоб зберегти всі одразу). Після npm run build посилання на гру в Telegram показуватиме саме цю картинку.
