## 4. Спіраль у hero: анімація

- **Геометрія.** 22 перекладини (мобільний: 18). Для перекладини i: θ = 0.52·i + φ. Кінці: x₁ = 50 + 44·sin θ, x₂ = 50 − 44·sin θ (% ширини). Розмір точки 9 ± 5·cos θ px, прозорість 0.5 ± 0.5·cos θ: точка, що «йде назад», менша й тьмяніша. Об'єм без WebGL і без 3D-трансформацій.
- **Обертання.** φ = φ₀ + 2π·t/14 с (повільний холостий оберт) + π·scrollY/висота екрана. Скрол докручує спіраль, тож вона реагує на рух пальця.
- **Зв'язок із «Шляхом зірки».** На десктопі поруч із кроками стоїть друга спіраль із 21 перекладини = 7 кроків × 3. Коли крок перетинає 60% висоти екрана (IntersectionObserver), його три перекладини фарбуються коралом (scaleX 0 → 1, 320 мс), номер і крапка кроку теж стають коралом. На мобільному роль спіралі грають коралові крапки біля номерів кроків.
- **Слабкий телефон** (deviceMemory ≤ 4 або hardwareConcurrency ≤ 4, або FPS < 45 за перші 2 с): 12 перекладин, холостий оберт вимкнено, лише від скролу; один rAF на сторінку; лише transform і opacity (без box-shadow, blur, width); спіраль поза екраном зупиняється.
- **prefers-reduced-motion.** Спіраль статична при φ = 0.6 рад, без холостого оберту й реакції на скрол. Усі 7 кроків одразу розкриті й підсвічені коралом, відбитки статичні.

## 5. Генетичний відбиток гри: точне правило

```
// 1. Ключ
key = name.normalize('NFC').trim().toLowerCase()
      + '|' + genreId + '|' + color.toLowerCase()
// genreId: slova · viktoryny · holovolomky · pamiat · druzi

// 2. Зерно: FNV-1a 32 біт по байтах UTF-8 ключа
h = 0x811c9dc5; for b in utf8(key): h = (h ^ b) * 0x01000193 mod 2^32

// 3. Генератор: mulberry32(h) -> r() у [0,1)

// 4. Палітра P = [колір гри, колір жанру, #EE8466, #F1ECE1]
phase = r() * 2π
for i in 0..15:
  amp = |cos(0.55·i + phase)|
  k   = 0.55 + 0.45·r()
  top    = round(3 + 11·amp·k)          // 3..14 одиниць
  bottom = round(3 + 11·amp·(1.5 − k))  // 3..14 одиниць
  c1 = P[floor(r()·4)]; c2 = P[floor(r()·4)]
// Порядок викликів r(): phase, потім (k, c1, c2) × 16
```

**Малювання.** Поле 16 однакових колонок, висота поля = 30 одиниць. У колонці дві смуги шириною 55% колонки, по центру по вертикалі, розрив 1 одиниця: верхня висотою `top` кольору `c1`, нижня — `bottom` кольору `c2`. Тло завжди темне (`#0E1714` або `#15221E`). Ті самі дані дають однаковий відбиток на картці, сторінці гри й у превʼю.

**Кольори жанрів:** Слова `#E9D8A6` · Вікторини `#A9C79A` · Головоломки `#E0A9B8` · Пам'ять і реакція `#D6B98C` · З друзями `#9FC1CF`. Колір гри задає клієнт; якщо він темніший за 3:1 до тла, у палітрі його замінюють на колір жанру.

**Контрольний приклад:** `слововир|slova|#ee8466` → seed `1430196453` → перекладини 0–3: (10, 11, #E9D8A6, #F1ECE1) · (11, 12, #EE8466, #EE8466) · (10, 9, #F1ECE1, #F1ECE1) · (6, 6, #EE8466, #EE8466).

**Еталонний код:** `design/ka-lib.cjs` (довідкова реалізація у форматі CommonJS, тому `.cjs`: проєкт має `"type": "module"`; перевірена на цьому контрольному прикладі командою `node design/ka-lib.check.cjs`; оригінальний `ka-lib.js` із Claude Design не отримано).

Приклади в макеті (сторінка 4): Слововир `slova · #ee8466`; Знавець `viktoryny · #a9c79a`; Злиття `holovolomky · #e0a9b8`; Дуель знань `druzi · #b7cba0`. Для трьох останніх очікуваних значень перекладин у PDF немає, тож перевіряти по них можна лише детермінізм.

## 7. Калькулятор (сторінка Слововира)

- Повзунок «Гравців за місяць» 50–5 000 (початково 500).
- «Частка тих, хто купує» 4% і «Зірок на покупця за місяць» 30 позначені «умовно».
- Курс: 0,013 $ за ★ і 41,5 ₴ за $.
- Результат: зірок за місяць (500 × 4% × 30 = 600 ★), ≈ гривень за місяць (324 ₴), підписка −99 ₴, чистий прибуток (225 ₴), за скільки місяців окупиться запуск 1 500 ₴. Якщо прибуток від'ємний: «у плюс від ≈ N гравців на місяць» (при умовних значеннях N = 153).
- Логіка на сайті лише з `src/lib/economics.ts` (не змінювати).
